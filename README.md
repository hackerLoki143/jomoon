# Moonlit Sunflower Surprise

Romantic Birthday Surprise Website Prompt 🌙🌻

Create a beautiful, immersive, romantic birthday surprise website with a Space + Moon + Stars + Sunflower theme, cinematic HD background, smooth animations, and interactive surprises.

1. Login / Welcome Screen

The first screen should be a beautiful login/welcome page.

Full-screen HD background featuring outer space, glowing moon, stars, and a dreamy galaxy.

Add a subtle animated starfield and floating particles.

Use a romantic aesthetic with purple, midnight blue, golden-yellow, and soft white lighting.

Show a glowing title:

“A little universe is waiting for you…” 🌙

Add a button: “Enter My Universe ✨”

When clicked, smoothly transition into the birthday experience.

2. Space & Moon Background

Use a high-quality 4K/HD space background.

A large realistic glowing moon in the background.

Stars twinkling softly.

Shooting stars occasionally cross the screen.

Clouds of nebula slowly move.

Add cinematic parallax movement when the mouse moves.

Create a dreamy, peaceful, magical atmosphere.

3. Birthday Countdown

The birthday date is:

29 November 2026

Show an animated countdown timer:

Days

Hours

Minutes

Seconds

Display it inside a glowing glass-style card.

Title:

“Counting down to your special day 🌻”

When the countdown reaches zero, trigger a special birthday animation with golden particles, fireworks, and a birthday message.

4. Sunflower Theme 🌻

Add beautiful sunflowers throughout the website.

Sunflowers slowly sway as if moving in the wind.

Golden petals gently fall in the background.

Use glowing golden light around buttons and important elements.

Mix moonlight blue and sunflower yellow for a romantic contrast.

Add a sunflower garden section that appears during scrolling.

5. Background Music 🎵

Add a romantic background song.

Include a music control button with Play / Pause.

Show a rotating vinyl disc or animated music icon when playing.

Music should start only after the user clicks the Enter button because browsers restrict autoplay.

Keep the music soft and romantic.

Remember music mute/play preference during the session.

6. Interactive Gift Box 🎁

Place a glowing gift box in the center of a magical space scene.

Gift box should have a realistic 3D design.

Add glowing ribbons and golden sparkles.

Make the box gently float and pulse.

Show text:

“I have something special for you…”

When the user clicks the gift box:

The lid opens with a smooth animation.

Bright golden light shines from inside.

Sunflower petals fly out.

Stars and sparkles explode softly.

A hidden birthday letter appears.

7. Birthday Letter / WhatsApp Message 💌

Inside the opened gift box, reveal a letter with handwriting-style typography.

Show a button:

“Open Your Surprise Message 💌”

When clicked, display a heartfelt romantic birthday message with a typing animation.

Add another button:

“Send / Open on WhatsApp 💚”

On clicking it, open WhatsApp with a pre-filled message using the WhatsApp link format (https://wa.me/PHONE_NUMBER?text=MESSAGE).

Use a placeholder phone number that can be edited later. Do not send the message automatically.

8. Special Time Activation ⏰

Set the special surprise activation time to:

11:11 AM — 29 November 2026

Before activation:

Show a locked gift box.

Show the countdown to the special activation.

Add a glowing “Waiting for the magic moment…” message.

Space and stars continue moving.

At 11:11 AM on the activation date:

The gift box unlocks automatically.

Moonlight brightens.

Sunflowers bloom.

Golden light rays spread across the screen.

The surprise message becomes available.

Trigger a beautiful cinematic animation.

Also allow the user to click the gift box manually once it unlocks.

9. Animations & Interactions

Smooth transitions between every screen.

Scroll-triggered reveals.

Floating sunflowers and petals.

Twinkling stars.

Shooting stars.

Moon glow animation.

Gift-box opening animation.

Typing effect for birthday letters.

Fireworks on birthday.

Soft hover effects.

Mobile-friendly touch interactions.

10. Design Style

Romantic cinematic fantasy.

Space and moon atmosphere.

Sunflower gold accent.

Midnight navy, deep purple, and golden yellow palette.

Glassmorphism panels.

Soft glowing effects.

Elegant handwritten fonts mixed with modern clean typography.

No clutter.

Beautiful and emotional rather than overly flashy.

11. Website Structure

Create a smooth experience in this order:

Welcome / Login screen

Enter my universe button

Animated moon and stars

Birthday countdown

Sunflower garden

Floating gift box

Gift opening animation

Secret birthday letter

WhatsApp message button

Final screen: “You are my favorite star in this universe 🌙🌻”

Build this as a complete, responsive, working website. All buttons, music controls, countdown, gift box, animations, and WhatsApp action must function properly. Use clean code and premium-quality visuals.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
